# 🚗 Ride Sharing App

VOYAA is a ride and car booking mobile application built using **Flutter**, designed to provide a smooth and user-friendly transportation experience.  
The app allows users to create accounts, view locations on a map, explore different car types, review trip details, view driver information, and interact with ride-related services.

It is developed using **Firebase Authentication + Cloud Firestore** for user authentication and user data, **SharedPreferences** for local data caching, and **Google Maps** for location display.  
VOYAA focuses on a modern interface, smooth navigation, and an engaging ride-booking experience.

---

## 📝 About the App

VOYAA provides a complete ride-service interface, starting from account creation and login and extending to location, car selection, trip details, driver information, payment options, and driver rating.

The app also supports:

- 🔐 User authentication
- 📍 Location and map
- 🚗 Car type selection
- 👨‍✈️ Driver details
- 💬 Chat with driver interface
- 💳 Payment options
- Driver rating

All built using modern **Flutter + Firebase** technologies.

---

## 🚀 Features

- 🏠 **Home:** Provides quick access to the main ride-related services through an organized dashboard.
- 🔐 **Authentication:** Register and log in using email and password with Firebase Authentication.
- 👤 **User Profile:** Displays the logged-in user's name and account information.
- 📍 **Location:** Displays a Google Map and requests location permission when needed.
- 🚗 **Car Type Selection:** Browse different car categories including Sedan, SUV, Van, Electric, and Luxury.
- 🧾 **Trip Review:** View trip details such as pickup location, drop-off location, date, time, driver, car type, and fare.
- 🚘 **Track Car:** Provides a car tracking interface with an estimated arrival time.
- 👨‍✈️ **Driver Details:** View information about the assigned driver and vehicle.
- 💬 **Chat with Driver:** Provides a chat interface for exchanging messages with the driver.
- 💳 **Payment:** Provides payment interfaces for cash and wallet options.
- **Rate Driver:** Rate the driver and submit feedback after the trip.
- ⚙️ **Settings:** Change email or password and log out from the account.
- 💾 **Local Data Caching:** Stores user information locally using SharedPreferences.
- 🗄️ **Cloud User Data:** Stores registered user information using Cloud Firestore.
- 🎨 **Modern UI:** Uses gradient backgrounds, custom cards, Google Fonts, and Font Awesome icons for a modern visual experience.

> **Note:** Some ride features such as car tracking, driver chat, trip details, payment, and driver information are implemented as app flows/UI and are not connected to a real-time ride, messaging, or payment service.
